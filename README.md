# Rewir

Служебный блокнот почтальона: города → улицы → дома → коды домофонов + заметки.
Интерфейс на польском, один JSON вместо базы данных, вёрстка под телефон.

## Запуск

```bash
pip install -r requirements.txt
python server/app.py            # локально: COOKIE_SECURE=0 python server/app.py
```

При первом запуске в консоли печатаются сгенерированные пароли — **сотрудника** и **администратора**. Запишите: повторно они не показываются, в файле лежат только scrypt-хеши.

Наружу — через туннель, который сам даёт HTTPS:

```bash
cloudflared tunnel --url http://localhost:8000
TRUST_PROXY=1 python server/app.py
```

`TRUST_PROXY` включать **только** за туннелем. Иначе любой подделает `X-Forwarded-For` и обойдёт блокировку по IP.

## Файлы

```
server/app.py       API + раздача статики
web/                интерфейс (HTML/CSS/JS, без сборки)
data/data.json      города, улицы, дома, коды, заметки   ← в git не попадает
data/log.jsonl      журнал действий                      ← в git не попадает
data/sessions.json  живые сессии                         ← в git не попадает
config/auth.json    хеши паролей + их версии             ← в git не попадает
```

`.gitignore` закрывает `data/` и `config/`. **Не убирайте эти строки.** Один коммит с кодами домофонов остаётся в истории репозитория навсегда.

## Вход и режим администратора

Вход один — **пароль доступа**. Дальше в шапке кнопка `Tryb administratora`: вводишь второй пароль и повышаешь текущую сессию, не перелогиниваясь.

- Права админа выдаются на **2 часа**, потом сессия сама опускается до сотрудника. В шапке тикает обратный отсчёт, рядом кнопка `Wyjdź z trybu`.
- Сессия сотрудника живёт **30 дней**, продлевается при заходе, переживает перезапуск сервера (`data/sessions.json`).
- Ни один пароль нигде не сохраняется — ни на сервере в открытом виде, ни в браузере. Только scrypt-хеш и токен сессии в `HttpOnly`-cookie.
- Смена **пароля доступа** поднимает его версию и мгновенно выкидывает всех. Смена **пароля админа** гасит все активные админ-режимы. Так закрывается доступ уволенному сотруднику.

Кому давать второй пароль — решаешь ты. Новичку он не нужен, проверенному сотруднику выдаётся и работает.

## Права

| | Pracownik | Administrator |
|---|---|---|
| Смотреть всё: города, улицы, дома, коды, заметки | да | да |
| Отмечать дома пройденными | да | да |
| Добавить дом | да | да |
| **Дописать** новый код | да | да |
| Писать и править заметку (INF) | да | да |
| Править и удалять существующий код, менять номер дома | нет | да |
| Удалять дома, улицы, города | нет | да |
| Менять пароли, читать дневник | нет | да |

Роль хранится в серверной сессии. В браузере её нет — подменить в localStorage бесполезно.

Сотрудник может *дополнять* базу, но не портить внесённое.

## Коды и заметки (INF)

У дома **список кодов**, не одно поле. Каждый код — ярлык плюс значение: `Klatka 1 / 1234K`, `Brama / 45B`, `Furtka / 7788`. Ярлык необязателен. До 12 кодов на дом.

Кнопка `INF` на карточке открывает: список кодов (админ правит и удаляет прямо там), поле `Dopisz kod` для всех, заметку до 400 символов. Дом с заметкой подсвечивает кнопку. Коды старше года помечаются `kody starsze niż rok`.

Старый формат (одно поле `code` + `entrance`) мигрирует автоматически: `entrance: "1"` превращается в ярлык `Klatka 1`.

## Подпись, дневник, рейтинг

Подпись вводится по желанию (кнопка рядом с ролью), хранится в localStorage и уходит в заголовке `X-Author`. Не ввёл — «Nieznany».

Каждое изменение пишется в `data/log.jsonl`: время, подпись, роль, IP, действие, объект. Полный дневник видит только администратор.

Рейтинг видят все. В зачёт идут только созидательные действия — **добавленный дом, дописанный код, сохранённая заметка**. Удаления и правки не считаются, иначе появится фарм «удалил-добавил».

Важно: подпись — не аутентификация. Kowalski может подписаться как Nowak. Рейтинг — это витрина и мотивация. Для разбора «кто это сделал» смотрите IP и время в дневнике, а не имя.

## Защита от перебора

- 5 неверных паролей с одного IP → блокировка на 5 минут.
- Задержка 0.4 с на каждый неверный ответ.
- Сравнение хешей в постоянном времени.
- Смена пароля администратора завершает все админские сессии.

## Чего здесь нет

- **Офлайна.** Данные каждый раз тянутся с сервера. Пока вкладка открыта — она живёт в памяти, но перезагрузка или выгрузка вкладки в фоне оставит пустой экран. Нужен service worker.
- Регистрации пользователей. Пароль общий на роль, подпись вводится вручную.
- Устойчивости к нагрузке: один Flask, запись под блокировкой.

## Ответственность

Коды подъездов — доступ в чужие жилые дома. База должна быть согласована с нанимателем, не содержать персональных данных жильцов и храниться на служебном устройстве. Устаревшие коды удаляйте.
